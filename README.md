## 📋 Sobre

O **Steamworks** reúne os programas, drivers e ajustes essenciais que você precisa logo após formatar o Windows — pensado especialmente para quem monta ou usa PC para jogos. Chega de perder tempo baixando um por um: instale tudo de forma rápida, limpa e otimizada.

---

## ✨ Recursos

| Recurso | Descrição |
|---|---|
| 🚀 **Instalação rápida** | Principais softwares e utilitários em poucos cliques |
| 🎯 **Otimizado para jogos** | Ajustes de sistema voltados a performance |
| 🧹 **Sem bloatware** | Só o essencial, nada de programas desnecessários |
| 🔧 **Personalizável** | Escolha o que instalar |

## 🚀 Como usar

```bash
# 1. Clone o repositório
git clone https://github.com/seu-usuario/steamworks.git

# 2. Entre na pasta
cd steamworks

# 3. Execute o script principal
./steamworks.exe
```

Depois, é só seguir as instruções na tela. 🎉
